# Network Traffic Analysis
## 1. Project Overview
This project analyses network traffic using tcpdump. 
The focus is on DNS requests, domain names and IP 
addresses.
## 2. Tools Used
- GitHub Codespaces - Linux terminal - tcpdump
## 3. Data Collection
A DNS capture file named dns.cap was used. The 
capture file was inspected using tcpdump.
## 4. Traffic Analysis
DNS traffic was filtered using port 53. DNS A records 
and AAAA records were examined. The analysis was 
saved in dns_analysis.txt.
## 5. Results
A total of 76 lines were recorded in the saved 
analysis file. The captured traffic was examined to 
identify DNS queries, responses and IP addresses.
## 6. Conclusion
This project provided practical experience analysing 
network traffic and investigating DNS communication
using tcpdump.
